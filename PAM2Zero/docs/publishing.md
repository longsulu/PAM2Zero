# GitHub contents

Upload the contents of this folder as the repository root. Keep `src`, `tests`, `configs`, `docs`, `README.md`, `THIRD_PARTY.md`, `pyproject.toml`, and the dotfiles.

Do not add the local Anaconda environment, raw datasets, checkpoints, prediction caches or experiment output folders. These are excluded by `.gitignore`.

The existing main weights remain external. A model-download URL and publication citation can be added when their public records are available. No authors, DOI or redistribution license has been invented in this package.
